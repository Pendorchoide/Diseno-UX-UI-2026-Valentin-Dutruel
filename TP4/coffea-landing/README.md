## Descripción

Landing page estática de una sola página para la cafetería ficticia Coffea. La interfaz se construyó con HTML5 semántico y CSS3, siguiendo el diseño del PRD y manteniendo una estructura modular con tokens, componentes y estilos responsivos.

## Objetivo

Replicar visualmente la propuesta de diseño de la marca Coffea, con una experiencia clara, accesible y adaptable a distintos tamaños de pantalla sin usar JavaScript ni frameworks.

## Características

- Header con navegación y búsqueda
- Hero principal con CTA
- Sección de categorías
- Carrusel de productos de café y postres
- CTA promocional con imagen decorativa
- Testimonios
- Newsletter
- Footer con links y redes sociales
- Diseño responsive entre 360 px y 1920 px
- Accesibilidad básica: landmarks, foco visible, skip link y uso semántico de etiquetas

## Stack

- HTML5
- CSS3
- Google Fonts
- SVG optimizados

## Estructura principal

- `index.html` — estructura principal
- `css/` — estilos y tokens
- `assets/` — imágenes e iconos

## Cómo visualizarlo

1. Abre la carpeta `coffea-landing`.
2. Ejecuta `index.html` directamente en el navegador, o usa un servidor local como Live Server.

## Despliegue

El proyecto está preparado para desplegarse como sitio estático en Netlify.
